## Что такое Swapl

**Swapl** — HR-tech платформа для поиска работы и найма сотрудников в формате свайпов.

Вместо длинной цепочки «поиск → отклик → ожидание → неизвестность» пользователь сразу видит карточки подходящих вакансий или кандидатов и выражает интерес одним действием.

Если интерес взаимный — создаётся **матч**, после чего стороны могут перейти к прямому общению.

> Наша цель — сделать поиск работы и сотрудников быстрее, проще и человечнее.
